# eShop Documentation

Welcome to the eShop documentation directory. This folder contains comprehensive guides for working with the eShop application.

## Available Documentation

### [PowerShell Best Practices Guide](./POWERSHELL_GUIDE.md)

A comprehensive guide for writing PowerShell scripts and commands in the eShop project. This guide covers:

- **Script Structure**: How to organize PowerShell scripts with proper header comments and sections
- **Documentation Standards**: Best practices for inline comments and documentation
- **Naming Conventions**: Consistent naming patterns for variables, functions, and parameters
- **Code Style**: Formatting, indentation, and readability guidelines
- **Error Handling**: Implementing robust error handling with try-catch blocks
- **Security Practices**: Managing secrets, validating input, and secure coding
- **Common Patterns**: Reusable patterns for progress indication, retry logic, logging, and more

**Who should read this:** Anyone contributing PowerShell scripts, automation tools, or deployment scripts to the eShop project.
